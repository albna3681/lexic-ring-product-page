# Lexic Cuf Ring - Product Page

Luxury jewelry product page built with HTML, CSS, and vanilla JavaScript.

## Features

- Responsive design (mobile, desktop)
- Shopping cart with local storage
- Image gallery with thumbnails
- Product options (color & size)
- Toast notifications

## Design

Based on [Figma Design](https://www.figma.com/design/4ad9MKcLpwOHwvco8bnHea/Technical-Tasks?node-id=0-1&p=f&t=EGwlD9afo1aWTW5N-0)

## Tech Stack

HTML5 • CSS3 • JavaScript (ES6+)
